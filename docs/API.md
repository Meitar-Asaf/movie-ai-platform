# API Endpoints

## Health
- `GET /health`

## Auth
- `POST /api/auth/register`
- `POST /api/auth/login`

## Movies (JWT required)
- `GET /api/movies`
- `POST /api/movies`
- `POST /api/movies/ratings`
- `POST /api/movies/watchlist`

## Recommendations (JWT required)
- `GET /api/recommendations`

## Admin (Admin JWT required)
- `GET /api/admin/stats`
